# 外贸选品助手 (xuanpin)

**简体中文** | [English](README_EN.md)

针对 **Temu 全托管** 卖家的选品决策工具：你在拼多多/热销榜单上发现潜力爆品 → 输入关键词 → 脚本自动去 1688 找货源、核算成本利润、生成 Excel 选品报告。

> 设计哲学：**趋势判断留给人，脏活累活交给脚本。** 你有电商经验、懂什么会火；脚本负责搜货源、抓价格、算账、标记风险。

## ✨ 功能特性

- 🔍 **1688 智能采集** —— 关键词搜索商品，自动抓取标题、批发价、起订量、销量线索、店铺信息
  - 三层解析策略（mtop 接口 → 通用 XHR-JSON → DOM 兜底），页面改版也能自动降级工作
  - 关键词 GBK 编码（1688 接口的坑），商品卡片多行价格文本精确解析
  - 持久化登录态：扫码一次，长期免登录
- 💰 **成本利润模型** —— 供货价上限 / 落地成本（采购+包装+送仓+超重附加）/ 保守与乐观双口径利润
- ⚠️ **风险自动标记** —— 标题命中品牌侵权词、需认证品类（玩具 EN71/CPC、电子 CE/FCC、食品接触 FDA 等）自动红字提示，新手避坑
- 📊 **Excel 选品报告** —— 按保守利润排序、负利润标红、商品链接可点击、参数留痕可复盘
- 🗄️ **价格历史** —— SQLite 记录每次采集快照，同一个词跑第二次就能看价格走势
- 📦 **供货监控与上下架建议** —— 已报价/在供的商品登记后，每次跑工作流自动比对 1688 最新采购价：涨价→建议下架(停供)、降价→建议加量/续报、断货→建议换源，并生成《供货监控报告》
- 🐞 **调试友好** —— 采集失败自动保存截图 + HTML + 原始接口数据，快速定位页面改版问题

## 🔄 工作流

```
拼多多/榜单发现潜力品 → Temu查同款真实零售价
        ↓
python main.py search "关键词" --retail 对标价
        ↓
脚本: 1688搜货源 → 抓批发价/起订量/销量 → 算成本利润 → 标记风险
        ↓
Excel报告(按保守利润排序) → 人工复核链接 → 决定是否报价
```

## 🚀 快速开始

环境要求：Python 3.10+，Windows / macOS 均可。

```bash
git clone https://github.com/77372562/xuanpin.git
cd xuanpin
pip install -r requirements.txt
python -m playwright install chromium

# 首次使用: 登录1688 (扫码一次即可)
python main.py login

# 日常使用: 关键词找货 (--retail 填你在Temu上看到的真实零售价)
python main.py search "沥水篮" --retail 15.9

# 可选: 指定预估重量(克)和采集页数
python main.py search "马克杯" --retail 19.9 --weight 350 --pages 3

# 不开浏览器的自检 (模拟数据跑通全流程)
python main.py test
```

### 🖱️ 图形界面（零命令行，推荐）

双击 **`选品界面.bat`**，浏览器自动打开操作页面：

- **候选清单**：在表格里直接增删改候选品（关键词 + Temu 零售价 + 可选重量），点保存
- **一键跑批量工作流** / **单品快查**（临时查某个品，不用进清单）
- **实时运行日志**：采集进度、TOP榜单直接在页面上滚动
- **报告文件**：页面上直接下载每个 Excel，或一键打开报告文件夹
- 登录也是点一下按钮（弹浏览器扫码即可）

命令行方式依然全部可用（`login` / `search` / `batch` / `test`）。

### ⚡ 命令行批量工作流

不想每天敲命令？用批量工作流：

1. 用**记事本**打开 `keywords.txt`，把你在拼多多看到的候选品写进去（一行一个）：

   ```
   # 关键词,Temu零售价,重量克(可选)
   沥水篮,15.9
   马克杯,19.9,350
   冰感毛巾,9.9
   ```

2. **双击 `每日选品.bat`** —— 脚本自动登录检查 → 逐个关键词采集核算 → 生成：
   - 每个品一份独立报告（`reports/`）
   - **一张汇总总表**：所有品的所有候选放在一起按保守利润大排名

3. 打开汇总表，从上往下看，只关注：保守利润>0、无风险标记、起订量拿得动的

清单里没写零售价的品，运行时会提示你补输入。Windows 任务计划里给 `每日选品.bat` 设个每天定时，就是全自动日报了。

## 📈 报告口径

```
供货价上限 = Temu零售价 × (1 - platform_take)    # platform_take 默认 0.5
落地成本   = 1688采购价 + 包装费 + 国内送仓费 (+ 超重附加)
保守利润   = 供货价上限 - 落地成本(采购价取批发价高值)
乐观利润   = 同上(采购价取批发价低值)
```

所有成本参数在 `config.yaml` 中可调，建议按你实际货代报价校准后再用。

## 🖥️ 打包成桌面软件（可选）

想脱离 Python 环境当独立软件用：运行 `build_exe.bat`，产物在 `dist\XuanPin\`，把整个文件夹拷到任意位置，双击 `XuanPin.exe` 即打开桌面窗口（数据存 exe 旁边，换电脑整体拷贝即可）。

## ⚙️ 配置说明

| 配置项 | 说明 | 默认值 |
|---|---|---|
| `costing.packaging_fee` | 二次打包耗材费 元/件 | 0.8 |
| `costing.inbound_ship` | 国内快递送仓 元/件 | 5.0 |
| `costing.free_weight_g` | 超重计费起点 克 | 1000 |
| `costing.overweight_rate_per_kg` | 超重附加 元/kg | 4.0 |
| `fees.platform_take` | 平台分成比例(零售价→供货价的折损) | 0.5 |
| `search.max_pages` | 每次采集页数 | 2 |
| `risk.brand_words` | 品牌侵权词库 | 迪士尼/宝可梦等 |
| `risk.cert_rules` | 需认证品类规则 | 玩具/电子/母婴等 |
| `enrich.top_n` | 每个关键词自动进详情页抓重量/阶梯价的候选数 | 5 |
| `temu.enabled` | 自动比价开关(清单缺零售价时搜Temu取参考价带) | true |
| `temu.proxy` | 访问Temu的代理(留空自动读系统代理) | 空 |

## ❓ 常见问题

**搜索结果为 0？** 先重跑 `python main.py login`；仍失败说明页面结构变了，把 `data/debug/` 下自动保存的截图/HTML/JSON 发给维护者即可快速修复。

**利润数字可信吗？** 成本端（采购价/重量/附加费）是脚本算的，收入端的 `--retail` 必须你自己去 Temu 实地查看填写——这一眼同时也是你判断竞争烈度的机会。

**会被 1688 风控吗？** 脚本用持久化登录态 + 随机翻页间隔模拟人工节奏，但请控制频率（一天几个词足够），仅用于个人选品分析。
