# 外贸选品助手 v1

针对 **Temu 全托管** 的选品工具：你在拼多多/榜单上看到爆品 → 输入关键词 → 脚本自动去 1688 找货、算成本利润、出 Excel 报告。

**分工原则：趋势判断留给人（你的国内电商经验），找货/比价/算账交给脚本。**

## 安装（只需一次）

```bash
pip install -r requirements.txt
python -m playwright install chromium
```

## 使用（三步）

```bash
# 1. 首次: 登录1688（扫码即可，登录态长期保存在 data/browser_profile）
python main.py login

# 2. 日常: 关键词找货（--retail 是该品在Temu上的目标零售价）
python main.py search "沥水篮" --retail 29.9

# 可选参数:
python main.py search "马克杯" --retail 19.9 --weight 350 --pages 3

# 3. 打开 reports/ 下的Excel报告，人工复核链接
```

报告按**保守利润**（按批发价高值核算）排序，红色标记 = 负利润或风险提示（疑似品牌词 / 需认证品类）。

## 工作流建议

1. 在拼多多热销榜/直播间挑关键词（已验证的爆品逻辑）
2. 去 Temu 搜同款，记下零售价 → 作为 `--retail`
3. 跑 `search`，从报告里筛：利润为正 + 无风险标记 + 起订量低的
4. 逐个点链接人工复核（质量、图片、供应商年限），再决定报价

## 利润口径（config.yaml 可调）

```
供货价上限 = 零售价 × (1 - platform_take)     # platform_take 默认0.5
落地成本   = 采购价 + 包装费 + 国内送仓费 (+ 超重附加)
单件利润   = 供货价上限 - 落地成本
```

`platform_take=0.5` 是"零售价约一半为供货价上限"的经验粗估，宁可保守。其他成本参数（包装、送仓、默认重量）都在 `config.yaml` 里，按你的实际货代报价调。

## 数据与调试

- `data/xuanpin.db` — SQLite，商品/供应商/**价格历史**（每次采集自动记录，可看价格变化）
- `data/debug/` — 采集失败时自动保存截图+HTML+原始JSON，**把这些文件发我就能修解析器**
- 1688 反爬较强：脚本用持久化登录态 + 随机翻页间隔，请控制使用频率、仅用于个人选品分析，遵守平台条款

## 常见问题

- **搜索时提示登录** → 浏览器窗口里扫码即可，脚本自动继续
- **采集到 0 个商品** → 先重跑 `python main.py login`；仍失败就把 `data/debug/` 的文件发我
- **怎么判断品能不能做** → 保守利润>0 且无风险标记只是入围线，还要人工看详情页：重量体积、是否有第三方验厂、近30天成交
